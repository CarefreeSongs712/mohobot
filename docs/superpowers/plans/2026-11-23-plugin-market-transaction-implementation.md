# #144–#147 插件市场事务实施计划

依据[已确认规格](../specs/2026-11-23-plugin-market-transaction-design.md)。在隔离市场分支实现；前置 PR 未在 `dev` 稳定之前不推送本堆叠。每一步先加失败用例、在同一隔离基线上确认失败原因，再实现并复跑控制用例。

1. **归档校验 #145。** 抽出可复用的归档 staging 原语，不改手工安装器公开形态。市场验证压缩包实际 SHA256、包根入口、清单身份、版本、兼容性，进 live 路径前准备好同卷候选；更新用实际旧清单判断版本。不匹配时断言 stop hook 未调用、旧目录和来源逐字节不变。运行 `tests/test_plugin_market_service.py`、`tests/test_plugin_installer.py`、`tests/test_plugin_entry_root.py`。
2. **来源快照 #147。** 持久化自定义源代次、规范 URL、给每源绑定目录快照与刷新序号；在来源变更边界作废旧代次，代理失败回退直连，再回退同身份缓存。给首次索引获取独立入口，冻结每次准备的索引条目和身份。并发测试用事件对齐旧刷新/旧下载晚完成；加同 URL 改名、同 ID 换 URL/删除重建及缓存进程重启测试。运行来源、市场解析与服务用例。
3. **事务与恢复 #146。** 单目标 journal 使用严格解析和受控路径，写明新旧来源和每个移动槽；用原子替换持久化决定，在应用发现前恢复。先写磁盘层单元测试和真实子进程 `os._exit` 断点测试（提交前、提交后、回退途中和清理），测试两种终态重复跑及矛盾状态不改证据。再接入文件锁内的来源读改写、同卷回收和可选数据隔离清理。日志不能删早于终态。
4. **目标生命周期 #144/#146。** 将归档准备和磁盘事务接入市场写入锁 → 插件生命周期锁；同名目标及目标启停状态在提交前重新读取。实现退役、暂存激活、提交后发布、旧版恢复及超时隔离，与 #156 工具暂存接口接合。加入唯一可写入口；取消只影响等待，不允许后台线程/钩子越过 owner 和提交边界。测试无关工具、事件和 tick；验证与配置、单插件重载、切换启停和应用关闭的顺序。
5. **面板与验收。** 接入认证路由和前端状态，更新市场文档，保留业务结果与审计结果的区分；#152 自身的审计修复与索引文档回归留单独提交。扩展真实 Firefox #154 探针至更新、回退、卸载及来源状态。隔离跑全量 pytest、独立并发/封禁/重载/冷启动脚本与静态检查。
6. **分支交付。** 前置 `dev` 合入后按实际 SHA 重放，不接入乙未合入的改动；按分工限制评审范围。确认 CI 和实际 Firefox、异常退出恢复证据后开一个以 `dev` 为基线的市场 PR。
