## 1. 把失败路径写成离线回归

- [x] 新增 `tests/test_plugin_config_transaction.py`：用真实临时目录、schema 和极小插件记录启动时值、回调值及字典身份。先用既有 Python 接口复现部分保存覆盖省略键、GET 返回旧格式、已存在 `{}` 被补写。

## 2. 实施共享视图和提交协议

- [x] `mohobot/file_store.py`：给锁内读取增加可选「缺失时创建」行为；仅首次缺文件写入默认值，已有空白、损坏、非对象或 `{}` 不重写。普通读取不传此参数。
- [x] `mohobot/interceptors/plugin_system.py`：激活候选加载走锁内读取（冷启与单插件重载都等待），共同的纯函数生成生效视图；对象空分支不生成补丁。保留同步 `get_plugin_config`，面板使用异步成对读取，两个路径都返回隔离的视图。
- [x] 事务 `commit_plugin_config` 先取生命周期锁、检查接纳和 schema，再启动单个提交任务。非空补丁用 `json_update` 合并最新磁盘值；同一任务完成文件提交与同步发布，调用方持锁等待、重复取消不传给底层任务。活动实例更新顶层字典后回调；停用、关闭接纳和空补丁都不启动新回调。旧 Python `save_plugin_config` 包装返回布尔值。
- [x] `mohobot/web_panel/app.py`：映射配置不存在、接纳关闭、写入失败与四类成功结果；成功响应来自提交任务，不再事后读档。用真实离线 ASGI 追加鉴权/状态、写盘失败、回调失败及返回字典隔离断言。
